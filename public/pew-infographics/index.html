Pew Infographics · curated report library

This app renders infographics from a declarative report file — add a report by dropping a file in reports/ and registering it. Charts follow a validated, colorblind-safe palette, and every chart ships a data table so no value is reachable by hover alone.

All figures belong to the Pew Research Center, which is not affiliated with this page. Each figure's immediate source is listed in the data table beneath its chart.
